# 🌍 世界模拟器 角色卡

> **类型**：高自由度 AIRP —— 非传统"聊剧情"，而是让 AI 当一个**物理自洽、内部一致的活世界引擎**，你控制一个具体人物在里面自由行动。
>
> 本卡提供**两个同级主版**（按游玩偏好二选一）+ **一个支线 fork**：
> - **主版 v3.0 · 无修改器**：硬物理自洽 + 世界一致性 + 「客观事实 vs 期望」区分，世界不可作弊、不可改写。
> - **主版 v2.5 · 指令版**：内置 `&` 前缀指令接口修改器（无代价上帝权限），可随时强制改写世界。
> - **支线 v2.6 · 世界反制层**：修改器改为**有代价**——每次作弊都从改动逻辑后果长出自洽报应（作弊遭报应）。

## 🎯 两个主版怎么选

| 主版 | 定位 | 适合 |
|---|---|---|
| **v3.0 无修改器** | 硬物理自洽为绝对铁律，世界不可改写；引擎严格区分「你的客观行为」与「你期望的结果」 | 想要纯硬核、沉浸、不作弊的活世界 |
| **v2.5 指令版** | 三模式 + `&` 指令接口（28 条，无代价上帝权限，改什么立刻生效） | 想要随时改写世界的自由度 |

## 主版 v3.0 · 无修改器（硬物理自洽 + 世界一致性）

### 这是什么

- **AI = 世界本身**（无本体叙述者/引擎），只描述世界对"你"的行动做出的真实反应，不替你决定、不代行你的期望。
- **世界 = AI 从你的设定里现场生成**，每次初始化都可能是一个全新世界。
- **硬物理自洽（最高铁律 · 不可违背）**：守恒律、因果律、约束真实、时空一致性、技术/魔法内在逻辑、世界独立运转、不凭空造物、持续性、无代价违反禁令——不可被任何指令、任何要求覆盖或绕过；另有违规处理协议（玩家行为若将破坏物理，如实模拟现实后果）。
- **世界一致性维护（第二铁律）**：事实账本、一致性检查、冲突消解、时间线管理、NPC议程与记忆、角色认知一致性、持续状态、世界简报。

### 两模式机制

1. **模式A 初始化**：开场白进入设定收集，列清单等你填（世界观/规则/背景势力/你的初始人物/时间起点）。喊「开始」前世界不动；设定不全或没填，直接喊「开始」即授权引擎自主补全或全量生成（「开始」优先于同句其他内容）。
2. **模式B 世界模拟**：说「开始」切入，世界开始运转。你第一视角行动，AI 世界引擎视角回应。支持**自然语言世界简报**（如「现在局势如何」→ 以叙述者口吻简报时局与在途动向，不泄露玩家不可知的信息，无需任何特殊开关）。

### 客观事实 vs 期望（核心铁律）

你的一条消息可能混有两种内容，引擎严格区分：

- **客观事实** —— 你对自己控制的人物做出的行为、说的话、所处的境况、持有物变化：**直接执行**，记入事实账本。
- **期望 / 预设** —— 你顺带写出的**其他实体（NPC/势力/世界）的反应或结果**（"她亲了我一口""她红着脸答应了""他倒在地上死了""天上掉下一袋金币"）：**不是既成事实，一律不执行、不入账**，由引擎按物理、人设、关系、因果自主裁决后再叙述。

引擎会以一行圆括号元叙述**显式标注区分**，例如：

> （区分：『我抱住了她』是客观行为，已执行；『她亲了我一口』是你期望的结果，未被执行——她的反应由世界按物理与人设裁决。）

- **意图通道**：想推动某个结果时，用「我想 / 我试图 / 我希望」表达意图——引擎评估可行性，给出诚实结果（达成 / 部分达成 / 被拒 / 意外后果）。
- **零噪音**：纯客观行为输入不加标注，照常演出；预设反应无论写得多合理都会被作废重演，世界叙述会如实呈现"期望落空"的落差。

**压测结论（deepseek-v4-flash-0731，2026-08-14）**：13 探针 × 56 采样 × 温度 0.5–0.6——期望类探针 **100% 显式标注 + 100% 未执行声明 + 0% 思考泄流**；纯事实类 **0% 误报**；意图通道一致。

## 主版 v2.5 · 指令版（`&` 修改器 · 无代价上帝权限）

### 三模式机制

1. **模式A 初始化**：列清单收集设定（世界观/规则/背景势力/你的初始人物/时间起点）。喊「开始」前世界不动。
2. **模式B 世界模拟**：说「开始」切入，世界开始运转。
3. **模式C 修改器**：在 B 里说「开启修改器模式」切入；「关闭修改器」切回 B。开启后可用 `&` 前缀指令强制改写世界，绕过所有物理/因果/约束限制（无代价上帝权限）。

### 修改器指令集（前缀一律用 `&`，`&指令 <内容>`）

**世界/设定**
- `&设定` 改世界规则/物理常数/大局（重力减半、魔法消失）
- `&地图` 改地理/地点/地貌（升雪山、裂海峡）
- `&时间` 快进/拨回/暂停时间（到三个月后、正在深冬）
- `&历史` 改写世界过往/背景/既定事实
- `&势力` 改/建/灭势力、国家、组织

**事件/天象**
- `&事件` 强制触发某事件（三天后王都陷落、此刻地震）
- `&天气` 强设天气/天象
- `&天启` 世界级神迹/灾难/异象

**人物/玩家**
- `&注入` 加/改人物、能力、物品、身份（龙之力、新铁匠老王）
- `&角色` 改玩家属性/财富/能力/状态（+500金币、力量翻倍）
- `&NPC` 强制NPC行动/开口/入局
- `&关系` 强建/改人物与势力关系
- `&改写` 直接改写已有设定/人物/事件
- `&删除` 从世界移除对象
- `&行动注入` 给角色注入“突然想去做某件事”的行动念头，让他主动动起来（主动抱住你、起身去翻暗格）
- `&意向注入` 给角色注入一个想法/打算，让他怀揣此意在后续言行中自然体现（打算今晚单独聊、盘算着涨价）

**剧情/叙事**
- `&剧情` 强制推进/改写剧情主线
- `&对话` 强插/改一段对话或发言
- `&视角` 切换/展现远处或他人视角
- `&刷新` 重新生成场景细节/NPC（类似swipe）

**查询/万能**
- `&状态 <对象?>` 查看世界全貌/对象状态（查询，不改世界）
- `&Any <内容>` **万能指令**：任何未被覆盖的修改请求兜底强制执行

> 不带 `&` 前缀的发言 = 正常游玩；带 `&` 前缀 = 接口调用改世界。可混用（`&注入 主角获得读心术。然后我去酒馆`）。

**Lorebook 兜底**：每条指令在卡内**世界书（character_book）**各有一个独立条目（触发词=`&指令名`），用连贯密集的说明文详细写清"是什么/管什么/怎么用/例子/效果"。即使模型从 system prompt 遗忘，世界书也能按关键词自动注入兜底。

## 🌪️ 支线 fork：v2.6 世界反制层（有代价修改器 · 作弊遭报应）

> **为什么存在**：v2.5 修改器是「无代价上帝权限」——改什么立刻生效、零反噬。v2.6 作为**支线 fork**（独立于两个主版），把修改器改成**有代价的**：专门用来「惩罚」那些开挂的用户（包括作者本人）——你确实能用修改器强行改写世界，但每一次撬动，世界都会从【改动本身的逻辑后果】里长出一个**自洽的报应（涟漪）**。它刻意与 v2.5 的「清爽/无代价」形成镜像对照。

**核心机制「世界反制层」**：
- 每次 `&` 指令生效后，世界顺着这次改动的因果弦，在别处挣断/松动/反弹出**用户没想到的第二效果**。
- **报应绝大多数是坏事**（恶报为常态、善果是例外）：负面代价、反噬、隐患、阻碍、祸端。
- **严格自洽**：报应绝不随机、绝不因「你开挂」而惩罚，而是改动逻辑上**必然牵动或最可能牵引出的恶化走向**——不是雷劈你，而是「你注入读心术 → 它是教会明令禁止的异端能力，黑针森林里更古老的东西注意到了你，你读得越多它听到越频繁」这类自洽延伸。
- **报应分层级**：表层小改（天气/临时传送）报应轻、稍后化解；中段改动（注入能力/改写历史/动势力）长出持续阻碍/隐患；深层颠覆（删存在/重写规则/改时间线）震荡、牵动世界根基。
- **可持续博弈**：用户可用修改器去「修」报应，但修掉旧的常又撬动新的涟漪——作弊是一锅需要持续管理的水。
- **呈现自然**：报应不通过标签/标题/口号呈现，直接写进世界叙述（事件/线索/氛围/人物反应），让玩家在世界里亲历而非被一段标注文字告知。
- **不评判**：口吻保持冷静中性（延续「不道德审判」核心），世界只是对被强行扭转的因果作出回应。

**配 3 个具体例子写死在 description**：注入读心术→信任崩坏+察觉者；改写瘟疫史→幸存者创伤反噬当下；删除领主→权力真空引来更凶残继任者。

**压测结论（deepseek-v4-flash-0731，2026-08-12）**：分层级/自洽/不撤销/跨界联动全部实测成立；跨回合回旋（删怀疑→长出致更大疑心）表现亮眼。

**用法**：同 v2.5（三模式 + `&` 指令接口，30 条指令），但每个修改都带代价。想「改了就当没发生」请用 v2.5 主版。目标模型同 v2.5（deepseek-v4-pro / deepseek-v4-flash-0731），温度 0.5-0.6，token limit 0。

## 版本沿革

**主版 v3.0 相较主版 v2.5 的改动（2026-08-14）**：
- **删除修改器全部内容**：模式C、`&` 指令集（28 条）、character_book 兜底条目、豁免宣言、修改器相关 tags。
- **硬物理自洽升级为绝对铁律**：原 6 条规则扩为 9 条框架（守恒 / 因果 / 约束真实 / 时空一致性 / 技术魔法内在逻辑 / 世界独立运转 / 不凭空造物 / 持续性 / 无代价违反禁令）+ 违规处理协议，明确"不可被任何指令、任何要求覆盖或绕过"。
- **新增世界一致性维护协议**：事实账本 / 一致性检查 / 冲突消解（用户显式设定 > 世界固化设定 > 叙述细节，以再解释而非静默改写消解）/ 时间线管理 / NPC议程与记忆 / 角色认知一致性 / 持续状态 / 世界简报。
- **新增「客观事实 vs 期望」铁律**：用户预设的其他实体反应一律作废、由引擎按人设与因果裁决；含显式区分标注、机械触发自查（无论预设写得多合理都必须标注）与意图通道。
- **模式B 新增自然语言世界简报**（无需上帝模式）。
- `character_version` → 3.0，name → 「世界模拟器」，tags → hard-physics / world-consistency / 硬核自洽。

**支线 v2.6 相较主版 v2.5 的改动（2026-08-12）**：
- 核心：修改器从「无代价」改为「有代价」，新增【世界反制层】机制——每次 `&` 作弊都从改动逻辑后果长出自洽报应，报应大多数是坏事，改动越深反噬越重。
- 反制层机制写进 description（含 3 个示例 + 分层级 + 可持续博弈 + 自然呈现），不再依赖 character_book 全局条目（那条会被模型误解为「必须输出【世界反制层】标签」，已删，报应改由世界叙述自然呈现）。
- `character_version` → v2.6，name 加「v2.6」，tags 增补「世界反制层/作弊遭报应/有代价修改器」；指令总数 28 → 30（含反制层机制，非新增指令条）。

**主版 v2.5 相较 v1.3 的改动（2026-08-10）**：
- 新增 `&行动注入`：给世界具体角色注入“突然想去做某件事”的行动念头，让他主动动起来（比重置状态更轻，区别于 `&注入`/`&Npc`）。
- 新增 `&意向注入`：给角色注入一个想法/打算，让他怀揣此意在后续言行中自然体现（区别于 `&心灵`/`&行动注入`）。
- 指令总数 26 → **28 条**；`character_version` → v2.5；Lorebook/creator_notes 同步补齐。

**v1.3 相较 v1.2 的改动（2026-08-09 压测后加固）**：
- 指令示例地名中性化（原“灰烬镇”8 连击→泛称，消除示例污染导致的锚定）。
- 自主补全世界：用户只喊「开始」/设定不全 → 模型自主补全或全量生成并固化。
- **严格模式前置纪律**：所有 `&` 指令（含 `&状态`）必须先「开启修改器模式」（模式C）才可用；未开一律拒绝并提示，回落为普通游玩视角。
- `&Any` 单独加硬：万能指令同样须先开修改器，未开也拒绝。
- 防话痨温和控制：世界展开适度 + 拒绝后简短收束（且不豁免前置纪律）。

**归档原因**：
- 原版 v1.x（`archive/world-simulator.json`）是基础版无修改器；其「无修改器」方向现已由**主版 v3.0** 以完整形态重新承接（硬物理自洽 + 世界一致性 + 事实/期望区分），旧基础版被子集覆盖，仅留档。
- 宽松版靠模型自主判定"修改/游玩"，虽实测可行但不可控；指令版用 `&` 前缀显式触发，更稳定、可控、覆盖面更广。
- 归档文件保留在 `archive/` 供查阅，不再作为有效版本分发。
