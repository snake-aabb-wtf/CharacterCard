# 🗂️ 角色卡归档

此目录存放**已废弃/已归档**的角色卡历史版本，仅供查阅，不再作为有效版本分发或使用。

## 归档列表

| 文件 | 原版本 | 归档原因 |
|---|---|---|
| `world-simulator.json` | 世界模拟器（原版，无修改器） | 无修改器功能，被指令版子集全面覆盖 |
| `world-simulator-modifier-loose.json` | 世界模拟器·修改器(宽松版) | 依赖模型自主判定"修改/游玩"，不可控；被指令版替代 |
| `world-simulator-render.json` | 世界模拟器·修改器(渲染/面板版) | 叠加酒馆助手交互面板（HUD+指令条），需插件且模型每轮输出完整 HTML（占 token、拖慢、楼层堆叠）；日常游玩用纯指令版即可，故弃用归档 |

## 当前活动版本

唯一有效版本位于上级目录：**`world-simulator-modifier-command.json`** 世界模拟器·修改器(指令版) — `&` 前缀指令接口 + 26条指令 + 世界书(Lorebook)兜底，稳定可控、覆盖面广、无插件依赖。

## 归档历史备注

- **原版**：最早的三模式初版（实际上只有两模式：初始化 + 世界模拟），本次迭代因加入修改器概念而被指令版取代。
- **宽松版**：曾实测通过（V4 Pro 能正确区分"读心术=修改/去酒馆=游玩"），但因自由度依赖模型理解力、调教成本高，决定以更可控的指令版为准。宽松版保留了完整历史功能，若要参考"自然语言改世界"的写法可查阅。
- **渲染/面板版**（2026-08-10）：在指令版基础上叠加酒馆助手交互面板（世界 HUD + 26 指令下拉条 + 模式门控），经实测调通（每轮完整 HTML 面板 + 用户指令写回聊天 + 模式 C 才可发送）。但面板依赖酒馆助手插件、且强制模型每轮输出完整 HTML（高 token 开销、拖慢生成、楼层堆叠），日常游玩功能上纯指令版已完全覆盖——故弃用归档。构建资产保留在上级目录 `make_render_card.py` / `panel_template.html`，若日后要复活面板版可重新生成。
