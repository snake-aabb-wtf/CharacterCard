# 🎭 CharacterCard — 角色卡集散仓库

这个仓库是我（以及 AI 自动化流程）生产的一批 **SillyTavern 角色卡（Character Cards）** 的合集。

## 说明

- **AI 自动化生产**：这些角色卡从设计、生成、压测、迭代到排版，全程由 AI 自动化流程辅助完成。
- **使用场景**：SillyTavern / TRPG / 文游（GM 向）等 AI 角色扮演环境。
- **目录约定**：每张卡一个子文件夹，内含角色卡 JSON、教程手册、README 等。
